# Base de Datos de Especies

Este directorio contiene la infraestructura de datos (JSON) para las especies (`AnimalProfile`) en WHO Animal.

## Estructura
- `species/`: Contiene los archivos JSON individuales o por lotes de especies.
- `taxonomy/`: (Reservado) Definiciones y esquemas taxonómicos.
- `media/`: (Reservado) Artefactos multimedia referenciados por las especies.

El contrato formal de los datos se encuentra en `docs/DATASET_SPEC.md`.
